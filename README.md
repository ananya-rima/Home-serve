# HomeServe - Full-Stack MERN Service Booking Platform 🚀

HomeServe is a comprehensive local service booking and management platform (similar to Urban Company) built using the MERN stack (MongoDB, Express, React, Node.js). It features role-based access for Customers, Service Providers, and Admins, strict time-based booking transitions, automated expiry cron tasks, and secure Razorpay payment integration.
